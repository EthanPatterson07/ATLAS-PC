# Purpose
MUX (Multiplexers) are used to turn multiple inputs into a single output line, saving money, wiring, and efficiency

# Concept
- A MUX is a gate that picks one input to pass its signal to the output
- If we call the picking variable Sel ("Sel" is just convention)
- We can say that when Sel is 0, the output will be A, and when Sel is 1, the output will be B
- We can call this output F
