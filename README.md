# ATLAS-PC
ATLAS PC is a hardware, firmware, and software engineering project that seeks to create a personal computer through my own design.

## Hardware Platform
ATLAS PC or Project ATLAS is a long-term independent project that focuses on building a personal computer from the ground up

##Status Phase 1 - Digital Logic
Currently developing:
- Digital logic components
- Multiplexers
- ALU
- Registers
- VHDL

## Long-Term Goals

- Custom CPU architecture
- Custom ISA
- FPGA implementation
- Custom ASIC
- Custom GPU
- Custom memory systems
- Custom motherboard
- Custom firmware
- Custom operating system
- Custom computer
- Eventually: custom laptop

## Technologies

- VHDL
- Verilog/SystemVerilog
- C
- Python
- FPGA
- PCB design
- ASIC design
